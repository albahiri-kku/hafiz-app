## كيفية رفع الملفات

من جهازك (PowerShell):

```powershell
cd <مسار_المشروع>
xcopy "C:\Users\abumo\Downloads\وثائق مجلس الأمناء\*" "public\documents\" /E /I /Y
git add public/documents
git commit -m "add: BOT secretariat source documents"
git push
```

## السلوك التلقائي

- زر **"تنزيل النسخة الأصلية (Word)"** سيبدأ تنزيل ملف `.docx` المطابق
  مباشرةً من هذا المجلد.
- زر **"تنزيل PDF"** سيولّد PDF من بيانات الفهرس عند عدم وجود ملف PDF
  مرفق (يمكنك إضافة نسخ PDF لاحقاً وتحديث `filePath` للملف المطابق).
- عند نشر الموقع على الإنترنت (Vercel/غيره) سيُعرض ملف Word مباشرة
  داخل النافذة عبر معاينة Office Online — لا حاجة لأي إعدادات إضافية.
