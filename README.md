# أرشيف أمانة مجلس الأمناء

الأرشيف الرسمي لوثائق أمانة مجلس الأمناء، يضم حزمة الحوكمة الكاملة (32 وثيقة)
بالإضافة إلى اللوائح والأنظمة الجامعية الصادرة عن
[مجلس شؤون الجامعات](https://www.cua.gov.sa/regulations-and-regulations/).

## المزايا

- **عرض مصنّف** للوثائق وفق ١٠ تصنيفات: الوثائق الحاكمة، السياسات،
  اللجان، الأداء والتقييم، الاجتماعات، القرارات، الإفصاحات، العضوية،
  المراسلات، اللوائح الجامعية.
- **بحث فوري** بالعنوان أو رقم المرجع (BOT-XXX-NNN) أو الوسوم.
- **نافذة استعراض** مع ميتاداتا كاملة (تاريخ هجري، جهة، تصنيف سرّية).
- **تنزيل النسخة الأصلية** بصيغة Word (.docx) مباشرة من الخادم.
- **تنزيل PDF** مولَّد ديناميكياً من ميتاداتا الوثيقة.
- **معاينة Office Online** للوثائق على البيئات المنشورة عامةً.
- **PWA** يعمل بدون اتصال بعد أول تحميل.
- **RTL** أصيل، خطوط عربية رسمية، وألوان تتوافق مع الهوية الحكومية.

## التشغيل المحلي

```bash
npm install
npm run dev
```

ثم افتح <http://localhost:5173>.

## بناء الإنتاج

```bash
npm run build
npm run preview
```

## بنية المشروع

```
src/
├── App.tsx                       # الموجِّه الرئيسي
├── components/archive/           # مكوّنات الواجهة (Header, Footer, Viewer, ...)
├── data/
│   ├── categories.ts             # تعريف التصنيفات
│   ├── documents.ts              # فهرس الـ 32 وثيقة
│   └── regulations.ts            # اللوائح الجامعية مع روابط cua.gov.sa
├── pages/archive/                # الصفحات (Home, Documents, Detail, Regulations, About)
├── types/archive.ts              # أنواع TypeScript
└── utils/
    ├── download.ts               # تنزيل Word/PDF + معاينة Office Online
    └── format.ts                 # تنسيق التواريخ الهجرية والأرقام العربية

public/
├── documents/                    # ملفات Word الأصلية (32 ملف)
├── icons/                        # أيقونات PWA
└── manifest.json
```

## إضافة وثيقة جديدة

١. ضع ملف الـ `.docx` في `public/documents/`.

٢. أضف سجلاً في `src/data/documents.ts`:

```ts
{
  id: 'BOT-XXX-NNN',
  reference: 'BOT-XXX-NNN',
  title: 'عنوان الوثيقة',
  category: 'foundation',          // أحد التصنيفات المعرّفة
  date: '1446-01-01',
  issuer: 'أمانة مجلس الأمناء',
  classification: 'عام',           // عام | داخلي | سري
  summary: 'وصف موجز…',
  tags: ['وسم1', 'وسم2'],
  filePath: f('اسم_الملف_بالكامل.docx'),
}
```

## النشر

ينشر مباشرة على Vercel/Netlify/Cloudflare Pages. الإعدادات الافتراضية لـ Vite
تعمل دون أي تعديل. ستُتاح معاينة Office Online تلقائياً عند فتح الموقع
على نطاق عام (غير localhost).

## الترخيص

الوثائق محتوى رسمي لأمانة مجلس الأمناء؛ يخضع استخدامها لسياسات الجهة المالكة.
كود الواجهة بترخيص داخلي للمؤسسة.
